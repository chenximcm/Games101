## 笔记特色

每篇笔记包含：
- **课程信息**：主题、阅读材料、B站视频链接
- **核心内容**：详细知识点 + LaTeX 数学公式 + 图示表格

## 课程四大板块

| 板块 | 内容 | 核心技术 |
|------|------|----------|
| **光栅化** | 将三维几何形体显示在屏幕上 | OpenGL、Shader、深度测试、纹理 |
| **几何** | 曲线、曲面、网格的表示与处理 | 贝塞尔曲线、曲面细分、网格简化 |
| **光线追踪** | 模拟光线传播生成逼真画面 | BVH、辐射度量学、路径追踪 |
| **动画与模拟** | 让场景动起来 | 关键帧动画、质点弹簧系统、流体模拟 |
